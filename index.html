👋 Bienvenue dans Léo

Avant de commencer, le parent configure deux choses. Elles protègent ton enfant et te permettent de suivre son travail.

Tu recevras un petit résumé les jours où ton enfant travaille, et une alerte si un sujet important apparaît. Choisis une adresse que ton enfant ne consulte pas.

Ce code protège l'espace parent : ne le donne pas à ton enfant.

📩 Un code à 6 chiffres vient d'être envoyé.

Regarde aussi dans les spams. Le code est valable 20 minutes.

📅 Contrôles à venir

Une ligne par contrôle (date, puis matière). Léo les ajoute aussi tout seul quand ton enfant en parle, et propose de réviser les jours d'avant.

🧠 Ce que Léo a retenu

Léo complète ces listes tout seul après chaque séance. Une idée par ligne, tu peux les corriger.

🧭 Modes autorisés

Coche les modes que cet enfant peut utiliser. Léo refusera gentiment les autres.

🗑️ Historique

Efface les conversations, les résumés de séances, les questions de jeu et les records de cet enfant. Ce que Léo a retenu reste, sauf si tu vides aussi la mémoire.

Les alertes importantes sont toujours envoyées tout de suite. Les mails restent discrets (« Suivi scolaire ») et ne contiennent jamais les détails sensibles : ceux-ci restent ici, derrière le code.
