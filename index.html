👋 Bienvenue dans Léo

Avant de commencer, le parent configure deux choses. Elles protègent ton enfant et te permettent de suivre son travail.

Tu recevras un petit résumé les jours où ton enfant travaille, et une alerte si un sujet important apparaît. Choisis une adresse que ton enfant ne consulte pas.

Ce code protège l'espace parent : ne le donne pas à ton enfant.

📩 Un code à 6 chiffres vient d'être envoyé.

Regarde aussi dans les spams. Le code est valable 20 minutes.
